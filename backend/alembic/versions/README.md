# Alembic Migration Versions

This directory contains all database migration scripts generated by Alembic.

## Usage

### Generate a new migration (auto-detect changes)
```bash
cd backend
alembic revision --autogenerate -m "description of changes"
```

### Apply all pending migrations
```bash
alembic upgrade head
```

### Rollback last migration
```bash
alembic downgrade -1
```

### View migration history
```bash
alembic history
```

### View current version
```bash
alembic current
```

## Naming Convention

Migration files are named with format: `{revision_id}_{slug}.py`

Example: `a1b2c3d4e5f6_add_user_table.py`
